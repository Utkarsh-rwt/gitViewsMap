## 🚀 Get Your Visitor Badge

Replace `YOUR_GITHUB_USERNAME` with your GitHub username and paste the following into your GitHub README.

### Badge

```md
![GitViewsMap](https://gitviewsmap.onrender.com/badge/YOUR_GITHUB_USERNAME.svg)
```

### Clickable Badge (Recommended)

```html
<a href="https://gitviewsmap.onrender.com/YOUR_GITHUB_USERNAME">
  <img src="https://gitviewsmap.onrender.com/badge/YOUR_GITHUB_USERNAME.svg" alt="GitViewsMap Visitor Badge" />
</a>
```

### Markdown Version

```md
[![GitViewsMap](https://gitviewsmap.onrender.com/badge/YOUR_GITHUB_USERNAME.svg)](https://gitviewsmap.onrender.com/YOUR_GITHUB_USERNAME)
```

### Example

```md
[![GitViewsMap](https://gitviewsmap.onrender.com/badge/octocat.svg)](https://gitviewsmap.onrender.com/octocat)
```

When someone visits your profile:

1. The badge view count increases.
2. Visitor location is recorded.
3. You can view all visitor locations on your personal map page.

### Your Personal Visitor Map

```text
https://gitviewsmap.onrender.com/YOUR_GITHUB_USERNAME
```
